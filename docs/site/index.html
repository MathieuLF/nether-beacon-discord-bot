Bots Discord autohébergés

Un repère pour les joueurs, la musique et la vie du serveur.

Alpha répond aux commandes et, si tu l’actives, gère la structure et les statistiques du serveur. Bravo ajoute la musique avec Muse, dans un service séparé.

Exemple de fonctionnement

Cette présentation ne mesure pas l’état d’une installation.

● Alpha + Bravo
ressources  identifiants enregistrés
permissions appliquées à la création
musique     Muse, service facultatif
stats       rafraîchies et regroupées
palworld    données publiques filtrées
pokédex     suggestions + cache
diagnostics réponses privées

Selon les besoins de ta communauté

Le profil minimal active l’aide et Palworld. pokemon ajoute le Pokédex. Le profil full active aussi l’administration du serveur selon un plan que tu dois vérifier.

Gestion du serveur

Audit, rôles, salons et permissions. Alpha réutilise les identifiants enregistrés et signale les conflits. Aucune suppression automatique de salon ou de rôle.

Musique avec Muse

Bravo utilise ses propres identifiants et son volume de données. Le profil Compose music est facultatif et indépendant du profil d’Alpha.

Pokédex

Fiches illustrées, talents, capacités et types avec suggestions. Les recherches et les données PokéAPI utilisent les noms anglais, comme charizard.

Vie de la communauté

Des espaces pour Palworld, Pokémon GO, Minecraft et Vault Hunters. Les événements vocaux publics respectent la confidentialité des salons privés.

Palworld

Statut et récapitulatif accessibles aux membres. Les mesures absentes, anciennes ou incomplètes sont signalées. Les annonces en jeu sont réservées au staff.

Statistiques et diagnostics

Compteurs vocaux en lecture seule. Les comptes précédés de ~ indiquent un cache incomplet. Les détails techniques sont réservés aux administrateurs.

Démarrer en local

Prévois Node.js 24, npm et Docker Compose v2. Commence avec une application Discord de développement. Muse demande une seconde application seulement si tu actives la musique.

  1. Préparer la configuration.

    Récupère le dépôt, copie .env.example vers .env, puis renseigne le jeton d’Alpha et l’identifiant du serveur. Garde BOT_PROFILE=minimal pour commencer.

  2. Installer et vérifier.

    Lance npm ci, puis npm run check. Ces vérifications ne connectent pas le bot à Discord.

  3. Initialiser les dossiers et démarrer Alpha.

    Lance npm run init:local, puis docker compose up -d --wait nether-beacon. Dans Discord, essaie /help.

  4. Activer les fonctions supplémentaires.

    Pour full, vérifie le plan du serveur et les intents Discord, puis capture les identifiants des ressources existantes. Pour Muse, configure ses identifiants et initialise son volume. Le guide décrit ces deux parcours séparément.
